Je continue en français parceque flemme de faire semblant mais je vais d'abbord faire un jeu qui se joue sur terminal et ensuite faire une interface graphique en 2D (j'aurai voulu faire de la 3D mais je reste réaliste dans mes capacités)
Le but sera de faire un jeu qui se joue en 1 contre 1 en se connectant a un serveur qui est un des joueurs depuis le jeu (je sais pas comment ça fonctionne je raconte surement nimporte quoi)

Le but est d'essayer de faire le jeu le plus opti possible (dans mes capacités et mes connaissances quoi)
